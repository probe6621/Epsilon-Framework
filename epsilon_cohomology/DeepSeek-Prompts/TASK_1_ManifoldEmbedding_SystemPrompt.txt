**Step 1: Understand Product Manifold Structure**
- X is a smooth manifold with model space ℝ and model with corners 𝓘(ℝ)
- We construct X_ε = X × (ℝ × ℝ) × (ℝ × ℝ) as a product of three manifolds:
  * Component 1: X (the base manifold)
  * Component 2: ℝ × ℝ (the first torus, represented in Lean)
  * Component 3: ℝ × ℝ (the second torus)
- Mathlib provides `Pi.chartedSpace` and `Pi.smoothManifoldWithCorners` for product structures
- The product inherits a smooth manifold structure via `Pi.instChartedSpace` and `Pi.smoothManifoldWithCorners`

**Step 2: Define the Inclusion Map**
- The canonical inclusion ι sends each x : X to (x, (0, 0), (0, 0)) : X × (ℝ × ℝ) × (ℝ × ℝ)
- This is a straightforward function application: fun x => (x, (0, 0), (0, 0))
- Type: X → X × (ℝ × ℝ) × (ℝ × ℝ)

**Step 3: Prove Injectivity**
- If ι(x₁) = ι(x₂), then (x₁, (0,0), (0,0)) = (x₂, (0,0), (0,0))
- By product equality, x₁ = x₂
- Use `Prod.ext_iff` and pattern matching on products

**Step 4: Prove Smoothness**
- The inclusion map is the product of three smooth maps:
  * Identity on X: id : X → X (clearly smooth)
  * Constant zero map: fun _ => (0 : ℝ × ℝ) (smooth constant maps)
  * Constant zero map: fun _ => (0 : ℝ × ℝ) (smooth constant maps)
- Use `continuous_const` for constant maps
- Use `Smooth.prod_mk` to combine: smooth products are smooth
- Use `Pi.smooth_iff` for product smoothness characterization

**Step 5: Combine into Embedding**
- An embedding is: injective + continuous open map
- Use `Embedding.mk` constructor with injectivity proof
- Open map follows from continuity and injectivity on a manifold (use `IsOpenMap.of_continuous` or manifold theorems)
- Alternatively: use `Embedding` definition directly with injectivity and openness

**Step 6: State Final Theorem**
- Combine `canonicalInclusion_smooth` and embedding properties
- Main theorem: `canonicalInclusion_is_smooth_embedding`

/-- The toroidal double-cover product space. -/
def ToroidalDoubleCoverSpace : Type* := X × (ℝ × ℝ) × (ℝ × ℝ)

/-- Inherit charted space structure for the product. -/
instance : ChartedSpace ℝ (ToroidalDoubleCoverSpace X) :=
  Pi.instChartedSpace ℝ fun _ => 𝓘(ℝ)

/-- Inherit smooth manifold structure. -/
instance : SmoothManifoldWithCorners ℝ (𝓘(ℝ)) (ToroidalDoubleCoverSpace X) :=
  Pi.smoothManifoldWithCorners ℝ (fun _ => 𝓘(ℝ))

/-- The canonical inclusion map ι : X → X_ε. -/
def canonicalInclusion : X → ToroidalDoubleCoverSpace X :=
  fun x => (x, (0, 0), (0, 0))

-- Part B: Injectivity

/-- The canonical inclusion is injective. -/
theorem canonicalInclusion_injective : Function.Injective (canonicalInclusion X) := by
  intro x₁ x₂ h_eq
  have : x₁ = x₂ := by
    -- From equality of triples, extract first component
    have h := congr_arg (fun p : ToroidalDoubleCoverSpace X => p.1) h_eq
    exact h
  exact this

-- Part C: Smoothness

/-- The constant zero map to ℝ × ℝ is smooth. -/
theorem smooth_const_zero_pair : Smooth (𝓘(ℝ)) (𝓘(ℝ)) (fun (_ : X) => (0 : ℝ × ℝ)) := by
  exact Smooth.prod_mk (smooth_const) (smooth_const)

/-- The canonical inclusion is smooth. -/
theorem canonicalInclusion_smooth : 
    Smooth (𝓘(ℝ)) (𝓘(ℝ)) (canonicalInclusion X) := by
  unfold canonicalInclusion
  apply Smooth.prod_mk
  · -- Component 1: identity on X
    exact smooth_id
  · -- Component 2: constant zero pair
    apply Smooth.prod_mk <;> exact smooth_const

/-- The differential of the inclusion map is injective at every point. -/
theorem canonicalInclusion_tangent_injective (x : X) :
    Function.Injective (tangentMap (𝓘(ℝ)) (𝓘(ℝ)) (canonicalInclusion X) x) := by
  sorry  -- Follows from structure of product: dι = (id, 0, 0) is injective

/-- The canonical inclusion is an embedding. -/
theorem canonicalInclusion_is_embedding : 
    Embedding (canonicalInclusion X) := by
  apply Embedding.mk
  · exact canonicalInclusion_injective X
  · exact fun _ => isOpen_univ.mem_nhds (by simp)

-- Part E: Main Theorem

/-- The canonical inclusion is a smooth embedding. -/
theorem canonicalInclusion_is_smooth_embedding :
    Embedding (canonicalInclusion X) ∧ 
    Smooth (𝓘(ℝ)) (𝓘(ℝ)) (canonicalInclusion X) := by
  exact ⟨canonicalInclusion_is_embedding X, canonicalInclusion_smooth X⟩
